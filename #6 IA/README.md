# Actividades de Inteligencia Artificial

Repositorio que reúne ejercicios prácticos, análisis de casos y prototipos de desarrollo relacionados con la aplicación de la inteligencia artificial y la construcción de soluciones tecnológicas.

## 📌 Objetivo del repositorio

Documentar y organizar las actividades realizadas, los procesos de análisis, las soluciones desarrolladas y los prototipos construidos durante el aprendizaje y la experimentación con herramientas de inteligencia artificial.

## 📂 Estructura del repositorio

| Carpeta / archivo | Descripción |
|---|---|
| `TRES CUPOS, OCHO ESTUDIANTES/` | Ejercicio de análisis y toma de decisiones para asignar tres cupos de acompañamiento académico entre ocho estudiantes. Se consideran criterios como notas, asistencia, contexto individual, riesgo académico y pertinencia de los recursos disponibles. |
| `EJERCICIOS DE ORDENAR/` | Ejercicios de lógica algorítmica desarrollados en Python para ordenar tres números. Incluye soluciones, pruebas y comparación de diferentes estrategias. |
| `WEB CON IA/` | Prototipo web funcional (MVP) para la gestión de inventario y preventa textil de **Divina Providencia**. Está orientado al control de bodega y a la preventa en ruta. |

## 🧩 Actividades del repositorio

### 1. Tres cupos, ocho estudiantes

**Propósito:** analizar una situación de asignación limitada de recursos y evaluar cómo cambian las recomendaciones de una IA según los criterios y la información que recibe.

**Aspectos trabajados:**
- Análisis de notas y porcentajes de asistencia.
- Consideración del contexto y las necesidades de cada estudiante.
- Comparación de consultas y respuestas generadas por IA.
- Identificación de supuestos, límites y posibles sesgos.
- Reflexión sobre la importancia del criterio humano en la toma de decisiones.

### 2. Ejercicios de ordenar

**Propósito:** practicar lógica de programación mediante algoritmos que ordenan tres números de menor a mayor.

**Aspectos trabajados:**
- Variables y entrada de datos.
- Operadores relacionales.
- Estructuras condicionales (`if`, `elif` y `else`).
- Comparación de distintas soluciones algorítmicas.
- Pruebas con números desordenados, repetidos, negativos y valores iguales.

### 3. Web con IA — Divina Providencia

**Propósito:** desarrollar un prototipo web para apoyar la gestión de inventario y la preventa de productos textiles.

**Características descritas:**
- Gestión de inventario.
- Apoyo al control de bodega.
- Flujo de preventa en ruta.
- Prototipo mínimo viable (MVP).
- Despliegue mediante Vercel.

## 📝 Organización y documentación

Cada actividad puede incluir, según corresponda:

1. **Contexto y objetivo:** descripción del problema o ejercicio.
2. **Desarrollo:** procedimiento, consultas, código o decisiones realizadas.
3. **Pruebas y evidencias:** resultados, capturas, tablas o casos de validación.
4. **Análisis:** comparación de alternativas, observaciones y limitaciones.
5. **Conclusiones:** aprendizajes y oportunidades de mejora.

- **Desarrollo web:** construcción del prototipo de gestión.
