HTML

lenguaje de marcado de hipertexto, que agarra el texto y lo presenta de forma diferente.

lenguaje interpretado (codigo que se ejecuta en tiempo real, linea por linea.)

con html se arma la estructura y elementos de la pagina web.

propiedades: 

target="_blank" abre una página o link en una nueva pestaña.

title="nombre" nos da información respecto al elemento cuando pasamos el mouse por encima.

CSS

con css podemos tomar los elementos creados con html y modificarle sus propiedades.
